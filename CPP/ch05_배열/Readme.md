# 배열 (Array)

배열(array)은 가장 기본적인 자료 구조 중 하나로, **연속한 메모리 공간**에 할당되는 특징이 있다.

---

## 배열 부트 캠프

다음은 배열에 관한 통찰력을 얻을 수 있는 문제다.

> **문제:** 정수 배열이 주어졌을 때, 짝수가 먼저 나오도록 재배열해 보라.

이 문제는 배열의 길이가 N이라고 했을 때, 추가 공간을 O(N)만큼 사용하면 쉽게 풀 수 있다.

그런데 **추가 공간을 사용하지 않고도** 풀 수 있다.

배열에서 양쪽 끝을 손쉽게 접근할 수 있는 이점을 떠올려 보자.

이 문제에서는 배열을 세 가지 부분 배열로 나눌 것이다:

1. **짝수**
2. **정해지지 않은 숫자**
3. **홀수**

초기에는 짝수와 홀수 부분 배열은 비어 있고, 정해지지 않은 숫자는 전체 배열이 된다.
정해지지 않은 숫자를 하나씩 순회하면서 원소를 홀수 혹은 짝수 부분 배열로 옮긴다.
짝수와 홀수 부분 배열의 크기는 증가하고, 정해지지 않은 숫자 부분 배열의 크기는 감소한다.

```cpp
void EvenOdd(vector<int>* A_ptr)
{
    vector<int>& A = *A_ptr;
    int next_even = 0, next_odd = size(A) - 1;
    while (next_even < next_odd)
    {
        if (A[next_even] % 2 == 0)
        {
            ++next_even;
        }
        else
        {
            swap(A[next_even], A[next_odd--]);
        }
    }
}
```

## 배열 문제를 풀기 전 꼭 알고 있어야 할 내용

- 배열을 앞에서 채워 나가면 오래 걸리지만, **뒤에서부터 채워 나가면** 빠를 수도 있다.
- 원소를 삭제해서 다른 원소들을 왼쪽으로 옮기기보다는, **삭제할 원소에 덮어쓰는 방법**이 나을 수도 있다.
- 배열로 표현된 정수를 다룰 때에는, **배열의 끝에서부터** 숫자를 처리해 나가는 방법을 고려해 보라. 혹은 배열을 뒤집어서 최하위 숫자를 배열의 첫 번째 위치에 오도록 만들 수도 있다.
- **부분 배열**을 사용하는 코드를 작성하는 데 익숙해지라.
- 배열을 사용할 때 **인덱스를 잘못 사용하는 실수**를 하기가 굉장히 쉽다.
- 실제 반환할 때까지 배열의 초기 상태를 유지하지 않아도 된다.
- 원소의 분포를 미리 알고 있을 때 배열은 좋은 자료구조가 될 수 있다.
- **2차원 배열**을 사용할 때는 열과 행을 동시에 처리하는 로직을 사용하라.
- 가끔은 문제의 세부 사항을 따라 해 보는 것이 문제를 분석적으로 푸는 것보다 쉬울 수 있다.

## 배열 라이브러리 이해하기

`array`와 `vector` 클래스에 대해 잘 알아야 한다.

| 클래스 | 특징 |
|--------|------|
| `array` | 크기가 **고정** |
| `vector` | 크기가 **동적** |

이외에도 `<algorithm>` 라이브러리에 유용한 함수가 많다.

### 할당과 초기화

```cpp
array<int, 3> A = {1, 2, 3};
vector<int> A = {1, 2, 3};
```

### 하위 배열 만들기

```cpp
vector<int> subarray_A(A.begin() + i, A.begin() + j);
```

### 2차원 배열 초기화

```cpp
array<array<int, 2>, 3> A = {{{1, 2}, {3, 4}, {5, 6}}};
vector<vector<int>> A = {{1, 2}, {3, 4}, {5, 6}};
```

### 동적 크기 조정 (vector)

`vector`는 동적으로 크기가 조정되므로 끝에 값을 추가할 때 자주 쓰인다.

```cpp
A.push_back(42);
A.emplace_back(42);
```

### `<algorithm>`에 포함된 주요 함수

```cpp
binary_search(A.begin(), A.end(), 42);   // 이진 탐색
lower_bound(A.begin(), A.end(), 42);     // 하한 탐색
upper_bound(A.begin(), A.end(), 42);     // 상한 탐색
fill(A.begin(), A.end(), 42);            // 채우기
swap(x, y);                              // 교환
min_element(A.begin(), A.end());         // 최솟값
max_element(A.begin(), A.end());         // 최댓값
reverse(A.begin(), A.end());             // 뒤집기
rotate(A.begin(), A.begin() + shift, A.end());  // 회전
sort(A.begin(), A.end());               // 정렬
```
